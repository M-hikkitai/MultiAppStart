# MultiAppStart

Windows の仮想デスクトップごとに、アプリ・URL・フォルダをまとめて起動するランチャーです。「デスクトップ 1 にタイマー、2 に音楽、3 に教材、4 にエディタ」のような作業環境を、プリセットとして保存して一度に立ち上げられます。

## 動作環境

- Windows 10 / 11
- Windows PowerShell 5.1（Windows に標準で入っています）
- ブラウザ（URL などは Windows の既定のブラウザで開きます。Chrome、Edge、Firefox などに対応しています）

## 使い方

`src\quickStart.bat` を実行すると、保存済みプリセットの一覧が表示されます。

```
保存済みプリセット:
  1) study
番号=起動 / N=新規作成 / D=削除 / Q=終了
```

| 入力 | 動作 |
|---|---|
| 番号 | プリセットの中身を表示し、Y/N で確認してから起動します。 |
| `N` | 新しいプリセットを対話形式で作成します。 |
| `D` | プリセットを選んで削除します。 |
| `Q` | 終了します。 |

起動が終わると、ツールを終了するかメニューに戻るかを選べます。

### プリセットを作る

`N` を選び、プリセット名を入力したあと、起動したいもののパスまたは URL を 1 件ずつ入力します。

- 1 件入力するたびに、表示用の名前を尋ねます。Enter だけなら自動で付けます。
- `.exe` / `.bat` の場合は、続けて引数を尋ねます。
- 空行を入力すると次のデスクトップに進みます。何も入力していないデスクトップで空行を入力すると完了です。

## プリセットの形式

プリセットは `src/presets/<プリセット名>.json` に保存されます。編集したいときは、このファイルを直接書き換えてください。

```json
{
  "desktops": [
    [
      "https://www.youtube.com/"
    ],
    [
      {
        "name": "Visual Studio Code",
        "path": "C:\\Users\\you\\AppData\\Local\\Programs\\Microsoft VS Code\\Code.exe",
        "args": ["C:\\work\\my-project"]
      },
      "C:\\work\\my-project"
    ]
  ]
}
```

- `desktops` の並び順が、仮想デスクトップ 1, 2, ... に対応します。
- 起動対象は、パスや URL の文字列か、`name` / `path` / `args` を持つオブジェクトで書きます。`name` と `args` は省略できます。
- JSON の中では `\` を `\\` と書きます。

`presets/` は個人環境のパスを含むため、Git の管理対象から外しています。

## 起動対象の開き方

書かれた内容の種類から自動で判定します。

| 種類 | 開き方 |
|---|---|
| `http://` / `https://` の URL | 既定のブラウザの新しいウィンドウ |
| `.html` / `.htm` / `.pdf` のファイル | 既定のブラウザの新しいウィンドウ |
| フォルダ | エクスプローラーの新しいウィンドウ |
| `.exe` / `.bat` | 実行（引数を指定できます） |
| その他のファイル | 既定のアプリ |

既定のブラウザは、Windows の「既定のアプリ」で https に割り当てられているものを使います。ブラウザの実行ファイルを特定できない場合は通常の開き方になり、新しいウィンドウではなく既存のウィンドウのタブとして開くことがあります。

## 注意点

- 起動中はキーボードとマウスに触れないでください。仮想デスクトップの作成と切り替えはキー操作（Win+Ctrl+D など）を送って行っているため、途中で操作するとウィンドウが意図しないデスクトップに開くことがあります。
- 実行するたびに仮想デスクトップが新しく作られます。既存のデスクトップは削除しません。
- いちばん右の仮想デスクトップから実行してください。新しいデスクトップは右端に追加され、最後に左へ戻る動きをするため、それ以外の位置から実行すると元のデスクトップに戻りません。
- ウィンドウが開き切る前に次へ進んでしまう場合は、`src/launchApps.ps1` 冒頭の `$WaitPerApp` と `$WaitPerDesktop`（秒）を増やしてください。
